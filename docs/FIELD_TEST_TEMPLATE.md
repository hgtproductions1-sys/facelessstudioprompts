# Document a field test

Complete a note after two real runs. Keep the source outputs and prompts with the production files. Change one variable between runs where practical, then document the result and any remaining limitation. Use evidence you have permission to publish and remove sensitive details before choosing the prompt and frames you will share.

Copy the relevant template below. Enter the completed fields in the playbook or prompt record under fieldTest. Image evidence is optional. Put approved WebP or AVIF frames under public/samples or use the Sanity image CDN for the configured project. Provide the matching alt text, intrinsic width and intrinsic height for each frame you include.
