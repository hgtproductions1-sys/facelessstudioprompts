# Founder checklist for prompt and niche samples

Start with the six featured niches and the 12 production-oriented prompt slots below. Use the most recent Search Console page-click report to reorder the prompt queue as traffic data becomes available. Each entry needs an actual output, the model/version, the exact prompt, relevant settings, alt text and the capture date.

In Sanity, create a **Sample output** and choose the page type and slug listed below. The optional static paths identify where the optimized files go when the output ships with the app.
