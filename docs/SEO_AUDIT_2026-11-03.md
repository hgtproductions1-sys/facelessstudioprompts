# SEO and AI crawlability changes — 3 November 2026

## Scope and evidence

Reviewed the two TMOD PDFs supplied by the owner against current source and a
public crawl. The PDFs are AdSense readiness reports, not Google Search Console
reports. Their 131-URL snapshot predates the five published Sanity articles.
The live baseline contained 137 sitemap URLs, all returning HTTP 200 with a
canonical, viewport, one H1, and image alt attributes.

Detailed before/after evidence is in the sibling workspace folder
`thefacelessprompt-research/seo-audit-2026-11-03`.

## Changes

- Keep complete search topics, adding the full publisher name only when the
  combined title fits within 65 characters. This is an editorial length target,
  not a Google ranking requirement or a promise about pixel-based truncation.
- Write descriptive prompt snippets instead of cutting instructions mid-sentence.
- Add worked examples and useful explanations to the free tools, Studio,
  AI tools directory, and production workflow.
- Add visible publisher attribution to prompts, niche playbooks, and resources;
  distinguish original video practice notes from the external video's creator.
- Link the article index from the homepage and relevant articles from the tools.
- Add a server-rendered browse-by-name prompt directory. The live link-graph
  audit found 13 templates whose links were only exposed after client interaction;
  the directory gives every template an HTML link from the main library.
- Add the publisher's real support contact to Organization structured data.
  No physical address, qualifications, or production results were invented.
- Prioritize the article cover image and retain responsive sources, dimensions,
  descriptive alt text, and lazy loading on secondary images.
- Explicitly allow OAI-SearchBot, PerplexityBot, and Claude-SearchBot. Repeat the
  API, admin, and preview exclusions in each group. Preserve the prior wildcard
  policy for training crawlers.
- Add `/llms.txt`, `/llms-full.txt`, and `/markdown/...` public representations
  generated from current source and the same published Sanity query as HTML.
  Each HTML page links its Markdown alternate; each text page declares its HTML
  canonical using an HTTP Link header. No private previews or tokens are exposed.
- Keep HTML at canonical URLs for all Accept headers. A tested negotiation
  prototype was removed because this Next.js version overwrote HTML Vary headers.
  Explicit alternate URLs avoid introducing representation-cache ambiguity.
- Preserve true 404 statuses and remove the nonexistent `/404` canonical from
  the custom error page. Reject prototype-property names in informational routes.
- Expand privacy information using actual service behavior; add `/cookies`, a
  local-data removal control, and Google's documented consent-revocation entry
  point. Retain the existing AdSense publisher ID, script, verification, ads.txt,
  and region-specific Google consent mechanism.

## Publication and indexing boundaries

Existing public URLs, canonical host, sitemap entries, Sanity articles, standalone
Studio, and planner remain in place. The new cookie policy adds one sitemap URL.
Static lastmod values change only for pages with substantive edits. Sanity dates
continue to come from the published documents.

The Markdown files are optional reading/discovery aids. Google states they are
not required for its generative AI search features. They do not guarantee ranking,
citations, crawling, or indexing.

## Report findings that do not justify a code change

- A custom branded 404 already existed and returned 404, rather than 200.
- Viewport tags and image dimensions existed. Empty alt on a decorative thumbnail
  inside an already-labeled link/button avoids a duplicate accessible name.
- The async AdSense script alone is not evidence of an above-content ad unit.
- Query parameters customize the planner and library. They already canonicalize
  to their clean public URLs; deleting them would break useful functionality.
- Word-count and readability thresholds are not a substitute for helpful content.
  Contact, changelog, legal, and interactive tool pages have different purposes.
- Domain age cannot be fixed in code. No invented DMCA agent, indemnification,
  company registration, address, or legal jurisdiction was added for a score.

## Verification

Run `pnpm exec tsc --noEmit`, `node scripts/verify-site.mjs`, and
`node scripts/verify-editorial.mjs`. The source suite checks rendering, internal
links, canonical URLs, JSON-LD, private-path exclusion, published text coverage,
readable 404 responses, and all 96 niche/duration planner combinations.

After release, crawl the sitemap and check the current Sanity articles, text
alternates, robots rules, private routes, and parameter canonicals. A user-agent
test confirms observed HTTP responses, not the treatment of verified vendor IPs.

The Google PageSpeed API returned 429 during this audit. The PDFs did not measure
field Core Web Vitals, and an HTTP timing snapshot is not an LCP/INP/CLS result.
Actual Google index coverage and field metrics require Search Console/CrUX data.
